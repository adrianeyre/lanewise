# Require system Git; route network operations through the git CLI

Lanewise requires a system Git installation (2.40 or later) and bundles none. All network operations (clone, fetch, pull, push) and porcelain-heavy operations (merge, rebase, anything that runs hooks) shell out to `git`. gitoxide (`gix`) handles fast reads (log, graph, status, diff), and the CLI covers anything `gix` doesn't do yet. Git Credential Manager, which is how we support SSO without handling passwords, only plugs in through Git's credential-helper protocol. Using the user's own `git` also gives us their SSH configuration, credential helpers and hooks for free. We rejected bundling Git and GCM (more to ship and keep patched), and rejected doing everything in a library (we'd need our own SSH and credential code).
